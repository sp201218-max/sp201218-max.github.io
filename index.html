About the "Frank Postiz" app

The Google app "frank-postiz" is a private publishing tool used only by the owner of the Frank Checks The Maths channel. It runs on the owner's own computer (a self-hosted copy of the open-source scheduler Postiz) and uses the YouTube Data API for one purpose: uploading and scheduling the owner's own videos to the owner's own YouTube channel.

It is not offered to the public and does not access anyone else's data.
